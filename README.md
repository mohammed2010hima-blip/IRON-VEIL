# IRON VEIL — The Last Shrine

لعبة قتال جانبية ثلاثية الأبعاد تعمل مباشرة في المتصفح. تتحرك الشخصيات يمينًا ويسارًا فقط، مع القفز واللكم والركل والصدّ والكومبو.

## التشغيل محليًا

ثبّت Node.js، ثم شغّل خادم الملفات المرفق من مجلد المشروع:

```powershell
node server.js
```

افتح بعدها `http://localhost:8000/`. يحتاج تحميل Three.js والخطوط إلى اتصال بالإنترنت.

## نشرها من GitHub Pages

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
4. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

## الملفات

- `game.js`, `index.html`, `style.css` — اللعبة وواجهة المستخدم.
- `الشخصية/` — نموذج المقاتل وحركاته.
- `assets/` — خلفية الساحة ومؤثرات الصوت.
- `AUDIO_CREDITS.md` — خريطة الأصوات ومصادر الأسماء.
